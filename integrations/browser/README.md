# "ContextPilot it" browser button (Chrome / Edge)

Adds a **ContextPilot it** button next to the title of any GitHub issue. Click it and your local ContextPilot app
opens with the issue's title, link and description already filled in - review it, then click **Prepare**.

The issue text goes only to `http://127.0.0.1` (your own computer). The extension reads nothing else.

## Install (about 1 minute)

1. Start ContextPilot (double-click **Start ContextPilot.cmd**) and open your project in it once.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and choose this `integrations/browser` folder.
4. Open any GitHub issue: the blue **ContextPilot it** button appears under the title.

Using a different port? Open the extension's **Options** and change it.
